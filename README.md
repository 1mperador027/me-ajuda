# Me Ajuda

Comparador de preços de eletrônicos, com foco em ajudar pessoas a avaliar ofertas e escolher melhor custo-benefício.

## Estado atual
Primeira versão demonstrativa (frontend estático). Os produtos e preços são exemplos fictícios; ainda não há consulta a lojas em tempo real.

## Próximas etapas
1. Publicar a interface.
2. Integrar uma fonte autorizada de ofertas (começando pelo Mercado Livre).
3. Normalizar produtos e comparar especificações, preço, frete e condições.
4. Adicionar histórico de preços e alertas.

## Desenvolvimento
A interface inicial está em `index.html` e pode ser aberta diretamente no navegador.

## Aviso
Não há chaves de API neste repositório. Credenciais devem ser armazenadas em variáveis de ambiente no serviço de hospedagem, nunca no código público.
